# 🏡 像素小镇 — AI 驱动的社会模拟

> 不是游戏，是一个 **活的世界**。

5 个 AI 角色在像素小镇上自由生活。每个人都有过去、有心结、有暗恋的人。他们不是按照脚本行动——每一次对话都是即兴的，每段关系都会随时间演化。你看到的不是 NPC，是**真正在思考的人**。

---

## ✨ 这不是普通的 Agent 模拟

### 🧠 8 层动机系统

每个角色的行为不是随机或规则的产物——他们真的有"内心"：

| 层次 | 系统 | 说明 |
|------|------|------|
| 1 | **6D 关系** | 信任/好感/尊重/吸引/嫉妒/怨恨 — 对每个人的感情都是立体的 |
| 2 | **加权记忆** | 重要的事不会被忘记，心结会持续影响力 |
| 3 | **目标 & 计划** | 长期目标驱动短期计划，不是走一步看一步 |
| 4 | **需求** | 饥饿/社交/疲劳/意义感 — 像真人一样被内在需求推动 |
| 5 | **流言** | 有可信度评估的流言传播系统 |
| 6 | **信念** | 对他人性格的判断 + 置信度 — 不轻易相信流言 |
| 7 | **5D 情绪** | 愉悦/悲伤/焦虑/愤怒/孤独 — 情绪影响一切行为 |
| 8 | **感知** | 只看到周围发生的事，信息不完全 |

### 🌅 日夜循环

时间真的在流逝。每个 tick = 30 分钟游戏时间。黎明 → 白天 → 黄昏 → 夜晚。22:00 以后，角色会回家睡觉。晨光中醒来的人，和午夜失眠的人，选择完全不同。

### 🗣️ LLM 驱动的真实对话

每个角色由 DeepSeek AI 独立控制。没有脚本——同样的场景给不同性格的人，回答完全不同。小梅听到阿诗的赞美会脸红，集市张则会想办法利用。

## 🎨 前端故事视角

不再是一串枯燥的事件日志。侧边栏三个 Tab：

### 📰 小镇故事
按日夜阶段分组，事件按重要性分级显示（💬 对话 / ★★★ 重要 / ★★★★★ 里程碑）。一键生成**今日日报**——自动统计最活跃的人、关系变化、流言传播、最孤独的人。

### 🗺️ 实时关系地图
5 人全景关系网络。绿色连线 = 正面，红色 = 负面，粉色虚线 = 暗恋。连线标签显示关系阶段（朋友/暗恋/对手/敌人）。悬停看共同记忆。

### 👤 角色视角
切换到任意角色的视角：她的故事时间线、5D 情绪雷达、当前目标、未解心结、对他人的真实看法。**你看到的不是数据，是一个人的内心。**

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/zhoumiaoooooo/pixel-town.git
cd pixel-town

# 2. 安装依赖（只需要 3 个包）
pip install -r requirements.txt

# 3. 选择一种方式启动：

# 方式一：DeepSeek API（推荐，效果最好）
$env:DEEPSEEK_API_KEY = "sk-..."
python main.py

# 方式二：Ollama 本地模型
# 确保 Ollama 已安装并拉取了模型
python main.py

# 方式三：Mock 模式（无需任何 API，使用内置逻辑）
python main.py

# 4. 打开浏览器
# http://localhost:8000
```

## 🔧 配置

所有 Agent 预设、世界地图、建筑都在 `config.py` 中。修改性格、关系、记忆、目标即可创建全新的故事线。

```python
# 示例：修改小梅对阿诗的初始关系
"init_relationships_2d": {
    "a3": {
        "trust": 4, "affection": 9, "respect": 6,
        "attraction": 10,  # 明恋了
        "jealousy": 3, "resentment": 0,
    }
}
```
